# Clinical Services Management Application

A Java client-server application developed for managing clinical services and related healthcare operations.

## Project Overview

The application is designed to support the management of clinical services through a client-server architecture and integration with an SQL database.

## Project Structure

- **Klijent** – client-side application and user interface
- **Server** – server-side application and application logic
- **Zajednicki** – shared classes and components used by the client and server

## Technologies

- Java
- Java Swing
- SQL
- MySQL
- NetBeans

## Main Features

- Patient management
- Doctor management
- Clinical service management
- Appointment management
- Billing and invoice management
- Client-server communication
- SQL database integration
